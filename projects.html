Five tools I built because the work in front of me needed them. All of them are in use.

Research instrumentation

Aerosol Instrument Dashboard

The analysis app for the Petters lab. An aerosol experiment produces several files per run from instruments that do not share a clock, and lining them up by hand is where errors get into the record. The dashboard watches for new files, identifies the run, corrects the clock offsets, merges CCN data with the matching DMA and CPC records, and files the finished run in a searchable library. A live panel streams readings from a LabJack on a Raspberry Pi while the experiment is still running.

  • Python
  • Streamlit
  • pandas
  • LabJack
  • Raspberry Pi
  • in daily lab use

Aerosol health

Lung Deposition Explorer

Particle size decides where in the airway a particle lands, which is why the same mass of aerosol can be harmless or damaging depending on how it is distributed. This tool takes a measured size distribution and reports the fraction depositing in the head, tracheobronchial and alveolar regions, so a distribution can be read as exposure instead of as counts.

  • Python
  • regional deposition model
  • size distributions

Engineering tooling

ChemE Excel Toolkit and Panel

An Excel add-in that loads the constants and correlations a chemical engineer reaches for into every workbook automatically, with a task pane for the heavier lookups: NIST Antoine coefficients, vapour-liquid equilibrium, and ternary liquid-liquid extraction. It removes the step where a correlation is retyped from a textbook and quietly transcribed wrong.

  • Excel add-in
  • VBA
  • Office.js
  • NIST data
  • VLE
  • LLE

Process control

OpenCPC Live

A desktop interface for an OpenCPC process control trainer over USB serial. It issues read-only commands and plots the response live, so a control loop can be watched as it settles rather than reconstructed from a logged table afterward.

  • Python
  • serial
  • process control
  • live plotting
