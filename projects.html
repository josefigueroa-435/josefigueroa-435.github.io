Instrumentation

Aerosol Instrument Dashboard

Python, Streamlit, pandas, LabJack, Raspberry Pi · Petters laboratory

An aerosol experiment produces several files per run from instruments that do not share a clock, and reconciling them by hand is where errors enter the record. The dashboard watches for new files, identifies the run, corrects the clock offsets, merges CCN data with the matching DMA and CPC records, and files the completed run in a searchable library. A live panel streams readings from a LabJack on a Raspberry Pi while the experiment is still running.

Exposure

Lung Deposition Explorer

Python, regional deposition model

Particle size determines where in the respiratory tract a particle deposits, which is why an identical aerosol mass can be innocuous or harmful depending on its distribution. This tool takes a measured size distribution and reports the deposited fraction in the head, tracheobronchial and alveolar regions, allowing a distribution to be read in terms of exposure rather than counts.

Engineering

ChemE Excel Toolkit and Panel

Excel add-in, VBA, Office.js

An add-in that loads the constants and correlations a chemical engineer reaches for into every workbook automatically, together with a task pane for heavier lookups: NIST Antoine coefficients, vapour-liquid equilibrium, and ternary liquid-liquid extraction. It removes the step in which a correlation is retyped from a textbook and silently transcribed wrong.

Control

OpenCPC Live

Python, USB serial, process control

A desktop interface to an OpenCPC process control trainer over USB serial. It issues read-only commands and plots the response as it arrives, so a control loop can be watched settling in real time rather than reconstructed afterwards from a logged table.
